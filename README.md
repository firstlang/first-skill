# First Code

Coding skill for First.

## Installation

In Codex, ask:

```text
Install the skill from https://github.com/firstlang/first-skill
```

Then start a new chat so Codex can load the newly installed skill.

## Notes

OpenAI's current packaging guidance treats installable shared skills as part of a plugin package: a root `plugin.json`, a `skills/` directory, and installation through a plugin marketplace source. This repository currently contains the skill directly, so the simplest path is to ask Codex to install it from the GitHub repository.
